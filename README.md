# LearnTrack – Student & Course Management System

## Project Description
LearnTrack is a console-based Student & Course Management System developed using Core Java.
The project focuses on practicing Java fundamentals such as OOP principles, collections,
exception handling, and clean code practices.

The system allows administrators to manage students, courses, and enrollments.
All data is stored in-memory using ArrayList.
